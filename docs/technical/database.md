## Миграции

Миграции выполняются через **{{migration_tool}}** (отдельный инструмент, не ORM).

### Структура папки миграций

```
migrations/
├── V001__initial_schema.sql
├── V002__add_users_table.sql
├── V003__add_indexes.sql
└── ...
```

### Команды

| Действие | Команда |
|----------|---------|
| Создать миграцию | `{{create_command}}` |
| Применить миграции | `{{migrate_command}}` |
| Откатить последнюю | `{{rollback_command}}` |
| Проверить статус | `{{status_command}}` |

### Правила

1. Миграции нумеруются: `V001__description.sql`, `V002__description.sql`
2. Одна миграция — одно изменение схемы
3. Миграции не редактируются после применения (только новая миграция)
4. Перед применением миграций — делать backup
