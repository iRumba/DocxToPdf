# Требования к проекту: DocxToPdf

## Init - 2026-05-26

### FR-1: Загрузка DOCX-файла через файловый диалог
- Описание: Пользователь может выбрать .docx файл через стандартный системный диалог выбора файлов
- Приоритет: high

### FR-2: Загрузка DOCX-файла через Drag & Drop
- Описание: Пользователь может перетащить .docx файл из файлового менеджера в окно браузера
- Приоритет: high

### FR-3: Отправка файла на сервер
- Описание: Клиент отправляет выбранный DOCX-файл на сервер через HTTP POST (multipart/form-data) на endpoint /api/convert
- Приоритет: high

### FR-4: Конвертация DOCX → PDF
- Описание: Сервер конвертирует DOCX в PDF через LibreOffice Headless (soffice --headless --convert-to pdf)
- Приоритет: high

### FR-5: Скачивание PDF-результата
- Описание: После успешной конвертации клиент автоматически скачивает полученный PDF-файл
- Приоритет: high

### FR-6: Обработка ошибок
- Описание: Интерфейс отображает понятные сообщения об ошибках: неверный формат файла, превышение размера, ошибка конвертации
- Приоритет: medium

### FR-7: Health-check endpoint
- Описание: Сервер предоставляет endpoint /api/health для проверки работоспособности
- Приоритет: low

## Технические требования

### TR-1: Backend — .NET 10 ASP.NET Core Minimal API
- Технология: .NET SDK 10.0.300 / ASP.NET Core
- Версия: 10.0
- Описание: Серверная часть реализована на ASP.NET Core Minimal API, запускается в Docker-контейнере

### TR-2: Клиент — React + Vite + TypeScript
- Технология: React 19, Vite 9, TypeScript
- Версия: последние стабильные (npm-пакеты)
- Описание: Одностраничное приложение с drag & drop интерфейсом

### TR-3: Конвертация — LibreOffice Headless
- Технология: LibreOffice (soffice)
- Версия: последняя стабильная из apt-репозитория Debian
- Описание: LibreOffice устанавливается в Docker-образ, конвертация через вызов Process.Start

### TR-4: Ограничение размера файла
- Описание: Максимальный размер загружаемого файла — 50 MB
- Настройка: через appsettings.json и client_max_body_size в nginx

### TR-5: Очистка временных файлов
- Описание: Временные директории удаляются после отправки результата (finally-блок)

### TR-6: Docker Compose
- Технология: Docker Compose v5.1
- Описание: docker-compose.yml для запуска сервера и клиента

### TR-7: .NET Aspire
- Технология: .NET Aspire 9.x
- Описание: AppHost для оркестрации сервера и клиента в режиме разработки

### TR-8: Контейнеризация
- Технология: Docker
- Описание: Сервер — dotnet/aspnet:10.0 + LibreOffice. Клиент — nginx:alpine
