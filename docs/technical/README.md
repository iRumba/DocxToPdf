# Техническая документация

## Структура

- `architecture.md` — архитектура проекта
- `branching-strategy.md` — стратегия ветвления
- `workflow.md` — рабочий процесс команды
- `requirements.md` — требования к проекту
- `database.md` — работа с БД, миграции
- `tools.md` — инструменты проекта (Docker, Kafka, Redis и т.д.)
- `secrets.md` — управление секретами
- `testing.md` — стратегия тестирования
- `deployment.md` — развёртывание
- Дополнительные файлы по мере необходимости

## Назначение

Описание внутреннего устройства проекта для разработчиков.
Архитектура, процессы, соглашения.
