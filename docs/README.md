# Документация проекта

Этот раздел содержит документацию проекта.

## Структура

- `user/` — пользовательская документация (наполняется по мере реализации)
- `technical/` — техническая документация (для разработчиков)

## Правила

- Документация должна быть декомпозирована: один файл — одна тема.
- Для каждого раздела есть свой README.md с навигацией.
- Документация обновляется синхронно с кодом.
- Пользовательская документация — часть артефакта разработки, отражает написанный код.
- Техническая документация должна давать полное понимание структуры, инструментов и особенностей.
- Секреты не документируются в коде — только в `technical/secrets.md`.

- [Техническая документация](technical/README.md)
